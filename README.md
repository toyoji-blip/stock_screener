# 株式財務スクリーニングツール（Web版）

## ファイル構成
```
webapp/
├── app.py               Flaskアプリ本体
├── screening_core.py    コアロジック
├── templates/
│   └── index.html       画面（新規/バッチ/履歴タブ）
├── outputs/             生成したExcel・履歴データの保存先
└── requirements.txt
```

## セットアップ・起動
```bash
pip install -r requirements.txt
python app.py
→ http://127.0.0.1:5000
```

## 画面タブ
- **新規スクリーニング**: 1銘柄をStep1〜4で分析
- **バッチ処理**: Excelで複数銘柄を一括処理
- **過去の分析**: 履歴の検索・再表示

## バッチ入力Excel形式
1行目ヘッダー、2行目以降データ、空白行で終了。
| コード | 決算月 | 予想DPS | 現預金-2 | 現預金-1 | 現預金 | 配当金支払総額-2 | 配当金支払総額-1 | 配当金支払総額 |
|--------|--------|---------|---------|---------|-------|--------------|--------------|------------|
| 4743 | 3 | 80 | 4356 | 5038 | 7808 | 1088 | 1353 | 2153 |
